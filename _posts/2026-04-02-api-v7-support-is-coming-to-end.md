---
title: Поддержка версии API V7 подходит к концу
layout: default
---
Релиз версии API V7 состоялся в январе 2022 года.
Позже, зимой 2024 года была выпущена версия V8, с тех пор V7 числится устаревшей.
Прогресс не остановить, и уже начиная с iikoRMS 9.5 выходят сборки с поддержкой V9,
а это значит, что V8 является устаревшей, V7 перестаёт поддерживаться
(подробнее см. [управление версиями]({{ site.baseurl }}/versioning.html)).

Если у вас остались плагины на V7, сейчас самое время перевести их на V8,
эта версия поддерживается всеми iikoRMS, выпущенными с зимы 2024 года (8.7+),
и будет поддерживаться ещё около двух лет.
