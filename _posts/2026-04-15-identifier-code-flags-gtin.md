---
title: Флаг IdentifierCodeFlags.Gtin
layout: default
tags: v10 v10preview1
---

Начиная с API V10Preview1 в перечисление [`IdentifierCodeFlags`](https://iiko.github.io/front.api.sdk/v10/html/T_Resto_Front_Api_Data_Orders_IdentifierCodeFlags.htm) добавлен флаг `Gtin = 32`, которым помечается код GTIN позиции заказа.

GTIN добавляется к позиции, когда товар добавлен в заказ сканированием DataMatrix:

* если товар не маркированный, у позиции будет только код GTIN;
* если товар маркированный, код GTIN добавляется к позиции вместе с кодом маркировки.

Такой код получает флаги `SendToFiscal | Gtin`. Раньше для него использовались флаги `SendToFiscal | Osu`, поэтому код GTIN нельзя было отличить от кода объёмно-сортового учёта.

Плагинам, которые анализируют коды позиций заказа, следует ориентироваться на флаг `Gtin`, а не `Osu`.

Кроме того, при разделении позиции по кодам маркировки теперь учитываются только коды с флагом `MarkingCode`; код GTIN на разделение не влияет.
