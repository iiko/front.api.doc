Добавлено свойство `IsInternetPayment` (признак расчёта в Интернет, тег 1125) в класс [`ChequeAdditionalInfo`](https://iiko.github.io/front.api.sdk/v9/html/T_Resto_Front_Api_Data_Payments_ChequeAdditionalInfo.htm).

С 1 сентября 2025 года вступают в силу изменения законодательства: в электронный чек при онлайн-расчётах обязательно включается тег 1125 "Признак расчёта в Интернет".

```csharp
[Serializable, PublicAPI]
public sealed class ChequeAdditionalInfo
{
    /// <summary>
    /// Internet payment flag (tag 1125).
    /// </summary>
    public bool IsInternetPayment { get; set; }
}
```

Свойство [`IsInternetPayment`](https://iiko.github.io/front.api.sdk/v9/html/P_Resto_Front_Api_Data_Payments_ChequeAdditionalInfo_IsInternetPayment.htm) позволяет плагинам корректно формировать фискальные чеки для онлайн-платежей в соответствии с требованиями законодательства.
