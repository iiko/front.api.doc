## ✅ Выполненные изменения

### 1. Основной дизайн (`_layouts/default.html`)

#### ✨ Что изменено:
- **Полностью переработанный CSS** с использованием современных стандартов
- **CSS переменные** для всех цветов, отступов и теней
- **Адаптивный дизайн** с поддержкой мобильных устройств, планшетов и десктопов

- **Градиенты и тени** для визуальной глубины

#### 🎯 Ключевые особенности:
```css
- Цветовая схема: Красный брендовый (#E31E24, iiko red) + Серый (#f3f4f6) + Акцентные цвета (по необходимости)
- Отступы: 280px боковое меню, max-width 1400px контейнер
- Шрифты: Inter (основной), JetBrains Mono (код)
- Breakpoints: 768px (mobile), 1024px (tablet), 1400px+ (desktop)
```

Ничего! Новый дизайн уже активен через обновленные `default.html` и `tagpage.html`.

### Полная активация (опционально):

1. **Темная тема:**
```html

```

2. **JavaScript улучшения:**
```html

<script src="{{ site.baseurl }}/assets/js/enhancements.js"></script>
```
