## 📱 Responsive Breakpoints

- **Desktop**: > 1024px - Полная раскладка с боковым меню
- **Tablet**: 768px - 1024px - Уменьшенное боковое меню
- **Mobile**: < 768px - Вертикальная раскладка

## 🌓 Темная тема

Для включения поддержки темной темы добавьте в `<head>`:
```html
<link rel="stylesheet" href="{{ site.baseurl }}/assets/css/dark-theme.css">
```

Темная тема автоматически активируется при настройке `prefers-color-scheme: dark` в системе пользователя.

## 📝 Рекомендации по использованию

### Для добавления новых страниц:
1. Используйте стандартный frontmatter с `layout: default`
2. Добавляйте теги для лучшей навигации
3. Используйте markdown для контента
4. Таблицы автоматически стилизуются

### Для кастомизации:
1. Измените CSS переменные в `:root` для своей темы
2. Настройте градиенты в header/footer
3. Измените шрифты через Google Fonts
4. Добавьте собственные анимации при необходимости
